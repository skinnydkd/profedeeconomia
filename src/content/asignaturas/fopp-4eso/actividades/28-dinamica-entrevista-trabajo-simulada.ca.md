## Plantejament

Tindre un bon CV obri la porta; l'entrevista decidix. I l'entrevista s'entrena: les primeres vegades tots ens posem nerviosos, contestem a destemps o ens quedem en blanc davant preguntes previsibles. Esta dinàmica dóna a cada alumne l'oportunitat de practicar en un entorn segur, passant pels tres papers per a entendre l'entrevista des de tots els angles.

Fer d'entrevistador ensenya què es busca; fer d'observador ensenya a vore allò que un mateix fa malament; fer de candidat és on s'entrena de veritat. La rotació garantix que tots passen pels tres.

## Objectius didàctics

- Practicar respostes a les preguntes d'entrevista més habituals.
- Prendre consciència del llenguatge no verbal (mirada, postura, salutació, to).
- Aprendre a gestionar les preguntes difícils sense bloquejar-se.
- Desenvolupar la mirada crítica en observar i avaluar altres candidats.

## Banc de preguntes (targetes)

```
HABITUALS
 · Parla'm de tu en un minut.
 · Per què vols este treball?
 · Quins són els teus punts forts?
 · Què t'agradaria aprendre ací?

DIFÍCILS
 · Dis-me un defecte teu.
 · No tens experiència, per què et contractaria?
 · Què faries si un client et crida?
 · Per què vas deixar la teua activitat anterior?
```

## Plantilla d'observació

```
 CRITERI                          | 1 | 2 | 3 | 4
 ──────────────────────────────────┼───┼───┼───┼───
 Salutació i primera impressió     |   |   |   |
 Claredat de les respostes         |   |   |   |
 Llenguatge no verbal (postura/mirada)|  |  |  |
 Gestió de la pregunta difícil     |   |   |   |
 Tancament i comiat                 |   |   |   |
 Una cosa que ha funcionat: ____________________
 Una cosa per a millorar: _______________________
```

## Passos

1. **Enquadrament i modelatge (8 min).** El professor explica els tres papers i modela una mini-entrevista (pot fer de candidat roín a propòsit i després bo) perquè es veja la diferència.
2. **Formació de trios i repartiment (4 min).** Trios. En cada ronda, un és candidat, un altre entrevistador i un altre observador. Es repartixen les targetes de preguntes i les plantilles d'observació.
3. **Tres rondes d'entrevista (33 min, 11 min per ronda).** En cada ronda: l'entrevista dura uns 6 minuts (l'entrevistador fa 3-4 preguntes, una d'elles difícil); després, 3 minuts de feedback de l'observador amb la plantilla; rotació de papers. Així els tres passen per candidat.
4. **Recollida d'aprenentatges (6 min).** Cada alumne anota, d'allò que ha viscut en els tres papers, els seus dos millors recursos i el seu punt més fluix a millorar.
5. **Tancament (4 min).** Posada en comú breu dels errors més comuns que han observat i dels trucs que millor funcionen (preparar el «parla'm de tu», convertir un defecte en alguna cosa en la qual es treballa, no parlar malament de ningú).

## Criteris d'avaluació

| Criteri | Descripció | Pes |
| --- | --- | --- |
| Exercici com a candidat | Respon amb claredat i gestiona la pregunta difícil | 30 % |
| Exercici com a entrevistador | Fa preguntes pertinents i manté el rol | 20 % |
| Qualitat de l'observació | Dóna feedback concret i útil amb la plantilla | 25 % |
| Reflexió personal final | Identifica els seus punts forts i la seua àrea de millora | 25 % |

## Variants i extensions

- **Variant entrevista en vídeo.** Gravar una entrevista (amb consentiment) i revisar-la. Vore's a un mateix és el feedback més potent que existix.
- **Variant panell.** Una entrevista amb dos entrevistadors alhora, per a entrenar situacions més exigents.
- **Connexió amb l'activitat 9.** El candidat es presenta a la mateixa oferta per a la qual ha fet el seu CV i carta en l'activitat 9, tancant el cicle complet de busca de treball.
